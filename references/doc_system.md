# 文档体系（engineer_doc/）

## 分档（三档，设计块开头定档）

| 档位 | 适用 | 文档骨架 | 状态机 |
|------|------|---------|--------|
| **轻量 Lite** | 单文件脚本 / 演示原型 / 小工具（≤5 个点） | 仅 `project_plan.md`（功能清单即任务清单，【状态】就地更新） | 待做 / 进行中 / 通过（+停滞） |
| **标准 Standard** | 常规应用（5~15 个点） | 完整体系（见下） | 5 态 |
| **旗舰 Enterprise** | 复杂多模块 / 多平台 / 多人协作（>15 个点） | 标准档 + 每层 `index.md` + 模块级讨论记录 | 5 态 + 块级看板 |

**定档规则**：设计块初始化文档前定。AI 按两个信号推荐——
- 交付质量：演示 → 轻量；标准 / 精细 → 标准；旗舰级 → 旗舰；
- 点数：≤5 → 轻量；5~15 → 标准；>15 → 旗舰；
- 两个信号冲突时**取高者**；用户可改。

**只升不降**：项目中途膨胀可升档并补建缺失结构；不主动降档。

## 总结构（标准 / 旗舰档）

```
<项目根>/
└── engineer_doc/
    ├── project_plan.md              # 总设计主文档（功能清单 + 状态标注 + 收尾总结 + 变更日志）
    ├── project_plan/                # 同名文件夹：总设计讨论记录
    │   ├── design.md                # 设计块工作记录
    │   ├── tech_stack.md            # 技术栈讨论
    │   ├── features.md              # 功能清单讨论
    │   └── ui.md                    # UI 讨论
    ├── develop/                     # 开发块
    │   ├── mode.md                  # 开发模式配置（YAML）
    │   └── <模块>/                  # 模块文件夹（对应 project_plan.md 模块树）
    │       ├── <点>.md              # 点主文档（功能开发文档）
    │       └── <点>/                # 同名文件夹：该点记录
    │           ├── process.md       # 讨论/决策过程（需要才建）
    │           └── work.md          # 任务记录（状态唯一事实源）
    └── test/                        # 测试块（按需，同构）
        ├── mode.md
        └── <模块>/<点>.md + <点>/
```

## 轻量档结构

```
<项目根>/
└── engineer_doc/
    └── project_plan.md              # 总设计 + 功能清单（带【状态】）+ 收尾总结
```

## 命名规则

- `engineer_doc/` 下所有文件与文件夹**不带 `_doc`/`_flow` 尾缀**（顶层 `engineer_doc/` 除外）；**文档类型由父文件夹决定**。
- **主文档 + 同名文件夹**成对：`project_plan.md` + `project_plan/`；`<点>.md` + `<点>/`。
- `<点>/` 内可放多类记录：`process.md`（讨论过程，需要才建）+ `work.md`（任务记录）。
- 文件名英文小写、短横线：如 `agent_list.md`、`tech_stack.md`。

## 查找方式（无记忆也能找）

- `rg "关键词" engineer_doc` —— 按功能名/模块名检索。
- `find engineer_doc -type f -name "*.md"` —— 看全量文档。
- 每层可放 `index.md`（目录索引：该层有什么、各文件一句话）。
- `work.md` 头部"相关文件"字段直接跳转。
- **命名即 ID**：点 = 文件夹名 = 文档名，`rg agent_list` 一击命中。

## 续作动作（跨会话恢复）

```
读 project_plan.md → 按功能清单【状态】找未完成点 → 读对应 <点>/work.md 状态流转
    → 从「进行中 / 停滞」处继续，不重头开始
```

- 轻量档：读 `project_plan.md` 功能清单，从状态不是【通过】的点继续。
- 块入口（开发/测试）的模式配置在 `mode.md`，续作时先确认"还是这个模式吗"。

## 初始化步骤

1. 确认项目根（当前工作区文件夹 / 新建项目根文件夹）。
2. **定档**（AI 按交付质量 + 点数推荐，用户确认）。
3. 按档位建 `engineer_doc/` 骨架 + `project_plan.md`（模板按档位取：标准/旗舰用 `project_plan_template.md`，轻量用 `project_plan_lite_template.md`）。

# 设计块流程

## 目标

设计主体项目结构（粗略框架），产出总设计文档 `project_plan.md`，各部分的讨论记录写入 `project_plan/` 同名文件夹；总设计不写功能细节（留给开发块）。

## 步骤（按序）

1. **项目位置**：当前工作区文件夹为项目根 / 新建项目根文件夹（可能需要创建目录）。
2. **项目名**（建目录前必问）：
   - 以当前工作区为根 → 问**实际中文名**（可不取中文名）；
   - 新建项目根 → **必须有英文名**（作文件夹名，如"AI IDE"→ `ai-ide`）。
3. **初始化文档**：建 `engineer_doc/` 骨架 + `project_plan.md`（模板见 assets/project_plan_template.md）+ `project_plan/` 记录文件夹。
4. **项目底层与技术栈**（无依赖问题可一批问）：
   - **目标平台**（专业用语，不用"端"）：Web / 移动 / 小程序 / 桌面 / 后端 / CLI，**可多选**；
   - **技术栈**：用户没说才问；**单选**（① AI 推荐一套（按层：语言/后端/前端/数据库/中间件/部署）② 备选 2 套 ③ 逐层单独讨论 ④ 自定义）；是否用 Docker 等容器化看用户选择；
   - **部署目标**；
   - **交付质量**：4 档单选——演示 / 标准 / 精细 / 旗舰级（安全、并发、性能全按最高标准）；可附加"详细讨论"选项（选中则展开安全/性能深入讨论）。
5. **设计方式**：总框架 + 细化 / 逐步开发（主界面 → 分界面）。
6. **功能清单**：
   - AI 按交付质量**从简单到详细**给推荐功能清单（可分多组），用户**多重多选框勾选**；
   - **最后**才问"还有没有其他功能"；
   - **不做每个功能的详细设计**（留到开发块的功能开发文档）。
7. **UI 需求**：
   - **UI 参与度** 5 档单选：① 精细（可视化 UI 设计，每个控件位置都问）② 逐页（每页组成+关键交互）③ 中等（页面清单+整体感觉）④ 风格（关键页+风格方向）⑤ 简单（全交 AI）；
   - **视觉风格**：推荐/建议/询问 模式；
   - **可视化预览/编辑**（精细/逐页/风格档）：AI 渲染交互式预览（含控制面板），用户对着图打磨位置与样式；需要灵感时用 WebSearch 搜参考 / 参考本机 UI 技能模板，提炼成样式变量。详见 references/ui_design.md。
8. **收尾**：汇总写 `project_plan.md`（项目基础 / 目标平台 / 技术栈 / 设计方式 / 功能清单（带【状态】标注）/ UI 需求），各部分讨论记录写入 `project_plan/` 对应文件并标状态；块结束给摘要 + 继续/停下/换块。

## 明确不做

- 范围边界（只按用户说的做，边界由功能建议自然带出）
- 架构草图
- 里程碑（顺序由开发块按功能清单自然推进）

## 项目位置命名分支速查

| 位置选择 | 项目名问法 | engineer_doc 位置 |
|----------|-----------|------------------|
| 当前工作区为根 | 中文名（可不取） | 工作区根下 |
| 新建项目根 | 英文名（必填） | 新项目根下 |

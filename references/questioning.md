# 提问规范

## 方式（优先工具）

- **优先调用"询问工具"**（选项卡片 + 自定义输入框），避免用户手打；**没有询问工具时才用纯文字**让用户输入。
- 每个问题都带：**1 个推荐 + 几个建议 + 1 个自定义输入**（用户可自由填）。

## 并行与依赖

- **无前置依赖的问题一次问多个**（如 目标平台 / 交付质量 / 设计方式 可一批问）。
- **合并前提**：仅当 agent 与询问工具都支持并行提问时才合并；不支持则逐个问。
- **有依赖的问题必须等前一个答完**（前一个答案决定后一个问法时，如"交付质量=旗舰级？→ 是否详细讨论安全/性能"）。
- **合并形态**：一批多个独立问题列表，每个问题各自作答（各带选项/自定义）——**不是**让用户用一段话回答多个问题。

## 信息使用

- 用户已明确说的信息（项目类型、技术栈、平台等）**直接按用户的来**，不重复问。
- 不确定 / 没说到的才询问。
- 有疑问就问，不替用户假设。

# UI 可视化设计机制

## 目标

UI 参与度为 **① 精细 / ② 逐页 / ④ 风格** 时，用"可视化预览 + 可编辑打磨 + 参考搜索"替代纯文字讨论，让用户**对着效果图打磨**，而不是脑补。

## 可视化渲染（预览）

- 用 HTML/CSS 渲染**真实页面预览**（真实按钮、卡片、布局、配色），内联渲染或打开预览面板给用户看。
- 支持深浅主题、多平台（Web / H5 直接预览；小程序先用 H5 近似，真机细节留到开发后）。
- 每个控件、间距、配色都必须"看得见"。

## 可编辑打磨（闭环）

- 首选：生成**带控制面板的交互式预览**——滑杆 / 取色器 / 选择器调整字号、间距、圆角、颜色、主题，用户**直接操作即改**。
- 位置调整：布局用可调节参数（flex / grid 数值、坐标），用户给目标或点选，AI 同步改样式变量。
- 迭代流程：渲染一版 → 用户反馈或操作 → 改样式变量 → 重新渲染 → 满意后定稿。

## 参考搜索（精美 UI）

- 需要灵感时用 **WebSearch** 搜索设计参考（配色、布局、组件规范，如 dribbble / behance / 组件库官网）。
- 参考**本机其他 UI 相关技能/模板**（如已装的 ui-design-studio、design-token 等技能、assets 模板），提取可复用规范。
- 把参考**提炼成样式变量**（色板 / 字号 / 间距 / 组件状态），落到 theme 文件；**不整段照抄**。

## 产出落盘

- 样式配置写成**主题变量文件**（色板 / 字号 / 间距 / 圆角 / 阴影 / 深浅色），进入项目结构，开发块直接引用。
- UI 讨论记录写入 `project_plan/ui.md` 或 `<点>/process.md`。

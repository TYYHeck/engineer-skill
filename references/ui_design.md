# UI 可视化设计机制

## 目标

UI 参与度为 **① 精细 / ② 逐页 / ④ 风格** 时，用"落盘预览页 + 批注闭环 + 可编辑打磨"替代纯文字讨论，让用户**对着真实页面点批注**，而不是脑补或用文字描述位置。

## 预览落盘（不是一次性渲染）

- 预览页**落盘成网页文件**（`<项目>/ui-preview/`），用户随时浏览器打开、刷新即看新版；AI 迭代用 **Edit 增量改**（不重渲染全量，省 token，也不占对话上下文）。
- 结构：
  ```
  ui-preview/
  ├── index.html          # 预览总入口（页面导航）
  ├── page-*.html         # 每页一个文件（自包含 CSS + 批注脚本）
  ├── theme.css           # 样式变量（色板/字号/间距/圆角/深浅色），开发块引用
  └── annotate.js         # 批注脚本（公共，注入每页）
  ```
- **每个可批注元素埋 `data-ui` 唯一标识**（如 `data-ui="login-btn"`），保证全局唯一、不撞名——这是批注定位的锚点。

## 批注闭环（攒批注 → 一键复制 → 粘贴给 AI）

- 预览页注入批注脚本（~30 行）：**点击任意元素 → 右下角批注条**（预填 `@[data-ui="xxx"] :: `，光标在留空处）→ 输入批注 → 添加；
- 批注列表显示在侧栏（可删除/重新编辑）；**「复制全部批注」按钮**自动整理成**按页面分组**的文本：
  ```
  【page-login】
  @[data-ui="login-btn"] :: 颜色太浅，改成 #E53E3E
  【page-home】
  @[data-ui="card-grid"] :: 间距太挤，gap 12px
  ```
- 复制：优先 `navigator.clipboard`，fallback `execCommand('copy')`，再兜底自动选中提示 Ctrl+C（file:// 双击打开也能用）；
- **AI 修改流程**：收批注文本 → 按 `【page】` 分组 → 每条 `@[data-ui] :: 批注` 对应一次精准 Edit → 覆盖生成该页 → 用户刷新看新版。处理完的批注清空。
- 进阶可选：批注自动写 `annotations.json`（本地服务 POST 或 File System Access 授权）——高频迭代时启用，默认走复制方案。

## 可编辑打磨（控制面板，保留不降级）

- 三档（精细/逐页/风格）都保留**带控制面板的交互式预览**：滑杆 / 取色器 / 选择器调整字号、间距、圆角、颜色、主题，用户**直接操作即改**（调参）；
- 控制面板管"调参"，批注管"指出位置改什么"，两者互补；
- 位置调整：布局用可调节参数（flex / grid 数值），用户给目标或点选，AI 同步改 theme.css。

## 精细档逐组件设计循环（硬约束）

**UI 参与度 = ① 精细时强制走此循环**，禁止一次生成全部页面/组件。三层粒度，逐层确认后才进下一层：

```
① 组件级：每个子组件单独走（如 导航栏 → 内容体 → 每区组件）
    预览：components/<组件>.html（片段级，几十行，比整页小 3-5 倍）
    讨论：选项化提问该组件样式参数（布局 / 配色 / 字号 / 间距 / 状态）
    确认：控制面板可调 + 批注反馈 → 用户说 OK 才放行下一个
    → 样式变量增量写 theme.css（短锚点 Edit）
② 页面组合：该页组件全过 → 组合整页预览 → 协调检查（间距 / 层级 / 视觉平衡）→ 确认
③ 全局回归：所有页完成 → 主界面回归（导航一致性 / 主题统一）→ 确认
```

- **每个组件必须有 预览 + 讨论 + 确认 三件套**才放行；"简单问一下"不算讨论（讨论 = 针对具体样式参数的选项化提问）；
- **结案护栏**：设计块收尾必须给 **UI 确认清单**（组件级已确认列表 / 页面组合已确认 / 全局回归结果），**未完成全部确认不得进入开发块**；用户明确说"先开发"才放行。

## 迭代收敛（不设硬轮次上限）

- 迭代轮次**不设硬上限**（真实修改次数不可预测）；
- 但同一页迭代**超 5 轮**时提示一次："锁定布局只调样式 / 继续改"——节奏提醒，不强制打断。

## 参考搜索（精美 UI）

- 需要灵感时用 **WebSearch** 搜索设计参考（配色、布局、组件规范，如 dribbble / behance / 组件库官网）；
- 参考**本机其他 UI 相关技能/模板**（如 ui-design-studio、design-token 等），提取可复用规范；
- 把参考**提炼成样式变量**（色板 / 字号 / 间距 / 组件状态），落到 theme.css；**不整段照抄**。

## 产出落盘与衔接

- 设计块：预览页 + `theme.css` 留在 `ui-preview/`，作为**项目 UI 原型资产**（可保存、可给团队看）；
- 开发块：引用 `theme.css` 样式变量进 `src/`（转化为目标框架的 token/变量文件），**不在开发块重复预览已定稿的页面**；新增页面或大改时按需开预览；
- UI 讨论记录写入 `project_plan/ui.md` 或 `<点>/process.md`。
